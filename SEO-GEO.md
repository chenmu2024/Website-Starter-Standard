# SEO / GEO Standard

## Keyword governance

- Approved core keywords are immutable unless explicitly changed by the project owner.
- Map one primary intent to one canonical destination.
- Avoid cannibalization, near-duplicate pages, and keyword stuffing.

## Required page fundamentals

- Unique title and meta description
- One clear H1
- Logical H2/H3 hierarchy
- Canonical URL
- Internal links to relevant tools/content
- Crawlable primary content
- Useful above-the-fold answer or utility
- Structured data where it truthfully applies

## GEO / answer-engine readability

Important pages should make key facts easy to extract:

- Direct answer/definition near the top
- Clear labels and descriptive headings
- Tables for comparable facts
- Examples for procedural concepts
- FAQ only when questions are genuinely useful
- Explicit units, assumptions, formulas and definitions for calculators/tools
- Sources/attribution where factual claims need them

## Technical checks

- robots.txt
- sitemap.xml
- canonical consistency
- noindex only where intentional
- 404 behavior
- redirects where needed
- Open Graph / social metadata
- language / hreflang where multilingual architecture requires it
